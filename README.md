# MacrodoseIQ v1.0 — Clean-Slate Full-Journey Harm-Reduction Companion
**Built by Flude · 100% Free · Zero-Knowledge Local-First Harm Reduction**

The sister application to **MicrodoseIQ**, purpose-built for intentional full-dose journeys, festival harm reduction, sober trip-sitting, and 30-day post-journey integration:
1. **Weight & Dose-Tier Reference Engine**: Calculates Threshold, Light, Common/Therapeutic, Strong, and Heavy reference tiers across 14 compounds (including MDMA weight-based ceilings and rave hydration rules).
2. **Interactive Reagent Colorimetric Lab & Fentanyl Strip Calculator**: Simulates Ehrlich, Hofmann, Marquis, Mecke, Froehde, and Morris color reactions + exact water dilution math.
3. **22-Class Medication Contraindication Screener & Pre-Flight Set/Setting Checklist**: Screens critical hazards (Lithium, Tramadol, MAOIs, DXM, Ketamine + Alcohol) and verifies space/sitter readiness.
4. **In-Flight Journey Phase Tracker & Sober Sitter Dashboard**: Tracks Come-Up, Peak Plateau, Return, and Afterglow phases with Zendo Project sitting principles.
5. **Breathing Exercise Circle & Offline Sound Sanctuary**: Interactive SVG breath pacer + offline synthesized Rhythmic Chants, Soft Rain, Brown Noise, and 432 Hz Singing Bowl + local MP3/FLAC player.
6. **30-Day Spaced Integration Journal**: Structured prompts for Day 1, Day 3, Day 7, Day 14, and Day 30 + HPPD & recovery check.
7. **MAPS, Zendo, DanceSafe & Fireside Hub + AES-256-GCM Device Vault**: Local `.enc` file encryption, zero cloud telemetry, and the Flude manifest.
